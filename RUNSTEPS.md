# POS Desktop — How to Run (Client Guide)

This is a **standalone desktop app**. You do **not** need XAMPP, MySQL, PHP, or
any server — everything is built in.

---

## Steps

**2. Open the app**

## Good to know

- **Your data is safe on updates.** Sales/products live in your Windows user
  profile, so reinstalling or updating the app never erases them.
- **Backups:** Settings page → **نسخ احتياطي للقاعدة**. A copy is saved to
  `Documents\PosBackups\`. Do this regularly and keep a copy on a USB/drive.
- **Printing:** in Settings, type your receipt printer's exact Windows name,
  then click **طباعة تجريبية** to test.

---

## If something goes wrong

- **App opens then closes / blank window:** wait 10 seconds and reopen. If it
  still fails, restart Windows and try again.
- **Login fails:** check Caps Lock; use the exact email/password above.
- **Receipt doesn't print:** confirm the printer is on and its name in Settings
  exactly matches Windows ▸ Printers, then use **طباعة تجريبية**.

Still stuck? Send the file `%TEMP%\pos-desktop.log` to your support contact.
